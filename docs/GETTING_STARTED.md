# Getting Started

This is the shortest path from opening the site to your first useful run.

## Choose your platform

Use the tabs below for the small differences that matter on each platform.

## Good first checks

Check these in order:

1. Can you open the sidebar?
2. Can you open the Resources page?
3. Can you upload a note or folder?
4. Can you run a one-round debate?
5. Does the report appear in History after it finishes?

If you are using email login instead of GitHub OAuth, the login screen supports separate sign-in, account creation, and password recovery modes. The recovery form sends a reset email and shows resend status in the UI.

## FAQ

**Do I need every provider?** No. Start with one provider, then add the rest later.

**Do I need to understand the internals before using it?** No. You can treat the app as a review workspace and ignore the implementation details.

**What is the fastest smoke test?** Open the site, upload one note, and run one round with one provider.
