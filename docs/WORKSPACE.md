# Workspace Guide

This guide explains the day-to-day workspace flow inside Debate Lab: how to add source material, organize it, keep conversations, and move finished outputs somewhere useful.

## What lives in the workspace

Each signed-in user gets a private workspace. The backend keeps uploads, notes, and chat exports separated so they do not collide with other users.

Signing out clears the current uploads and cloned repository content from the local workspace, so a fresh session starts clean.

## Upload a file

You can upload a file from the right panel in the web UI or create one from the workspace area.

### In the web UI

1. Open the Arena or Resources screen.
2. Find the upload area in the right panel.
3. Click the upload box and choose one or more files.
4. The workspace updates after the backend stores the content.

## Create a project folder

Folders help when you want to keep drafts, references, and final exports separate.

### In the web UI

1. Type a folder name or nested path for your project structure.
2. Click Create.
3. Nested folders are created automatically.

### What this is good for

- separate one project from another
- keep uploads and exports grouped together
- store raw notes without mixing them with final reports

## Save a conversation

When you ask follow-up questions about a report, you can save the exchange in the conversations area of your workspace.

That gives you a durable record of:

- the report you discussed
- your follow-up questions
- the assistant's replies

## Clone a repository

You can clone a GitHub repository into your workspace for review.

Only GitHub URLs are accepted. That keeps the clone workflow narrow and easier to secure.

## Example session

1. Create a couple of project folders.
2. Upload a proposal or draft.
3. Clone a repository if you want the agents to inspect code.
4. Run a debate.
5. Save the report.
6. Save the follow-up conversation.

## Practical tips

- Use short, descriptive folder names.
- Keep raw input separate from finished output.
- Save chats when you want an audit trail of a review decision.
- Delete files you no longer need so the workspace stays easy to scan.
